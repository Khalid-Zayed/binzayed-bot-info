## ✨ What This Bot Does

Bin Zayed Bot is a custom-built Discord companion for one server, focused on three things: keeping the server organized, giving members something fun to do together, and letting the server owner customize who can do what.

### 🛡️ Moderation
Ban, kick, timeout, warn, and message cleanup — plus a fully custom permission system so the owner can decide exactly which roles are allowed to use which commands, no coding required, just a simple in-Discord command.

### 💰 Economy
Members earn currency and XP just by chatting, can claim daily rewards, browse a shop, and check a leaderboard to see who's on top.

### 🎮 Games
A full lineup of multiplayer and solo games, including:

- **Mafia** — with two modes: a quick basic version, and a full version with eight distinct roles, a day/night cycle, and a live jury-trial system where the server votes on who to believe.
- **XO & Rock-Paper-Scissors** — winner-stays-on tournaments where anyone can jump in.
- **Roulette** — a real animated spinning wheel that picks someone, who then chooses who gets eliminated.
- **Musical Chairs, Hide & Seek, word-category games, flag guessing, color guessing, unscramble, speed-typing,** and more.
- **A session points system** for tracking scores across a run of mini-games with friends, with a simple reset when you're ready for the next round.

### 🖼️ Live-Generated Visuals
Some game moments — like the roulette wheel and the Mafia role breakdown — are rendered as real images and animations on the spot, not static text.

## 🔒 Privacy

Bin Zayed Bot only stores what its features need to function (balances, warns, permissions, game stats) — all on infrastructure controlled directly by the server owner, with nothing sold or shared with advertisers. See the full [Privacy Policy](./PRIVACY_POLICY.md) for details.

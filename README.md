## ✨ What This Bot Does

Bin Zayed Bot is a custom-built Discord companion for one server, focused on three things: keeping the server organized, giving members something fun to do together, and letting the server owner customize who can do what.

### 🛡️ Moderation
Ban, kick, timeout, warn, message cleanup, and channel lock/unlock — plus a fully custom permission system so the owner can decide exactly which roles are allowed to use which commands, no coding required, just a simple in-Discord command. There's also a lighthearted "prank" version of the classic kick-joke command that never actually removes anyone.

### ⚙️ Server Management
Welcome and leave messages, level-based automatic roles, a dedicated server activity log (message edits/deletes, bans), a simple auto-responder for common questions, and an admin command to have the bot post any custom message — all configurable directly through Discord, no dashboard needed.

### 💰 Economy
Members earn currency and XP just by chatting, can claim daily rewards, browse a shop, check a leaderboard, and view a generated rank card showing their level, server rank, and balance at a glance. Admins can also grant or deduct currency from anyone directly.

### 🎮 Games
A full lineup of multiplayer and solo games, including:

- **Mafia** — with two modes: a quick basic version, and a full version with eight distinct roles, a day/night cycle, and a live jury-trial system where the server votes on who to believe.
- **XO & Rock-Paper-Scissors** — winner-stays-on tournaments where anyone can jump in.
- **Roulette** — a real animated spinning wheel with players' own names on it that picks someone, who then chooses who gets eliminated.
- **GeoGuessr-style guessing** — a join-based round where players race to reserve the correct country from a genuinely random real-world photo; the closer a guess is geographically, the more points it earns, first to 100 wins.
- **Musical Chairs, Hide & Seek (with rotating random search turns), word-category games, flag guessing, color guessing, unscramble, speed-typing,** and more.
- **A session points system** for tracking scores across a run of mini-games with friends, with a simple reset when you're ready for the next round.
- Only one game runs per channel at a time, with an admin command to force-stop a stuck game.

### 🖼️ Live-Generated Visuals
Game moments — the roulette wheel, the Mafia role breakdown, and personal rank cards — are rendered as real images and animations on the spot, not static text.

## 🔒 Privacy

Bin Zayed Bot only stores what its features need to function (balances, warns, permissions, game stats) — all on infrastructure controlled directly by the server owner, with nothing sold or shared with advertisers. See the full [Privacy Policy](./PRIVACY_POLICY.md) for details.
